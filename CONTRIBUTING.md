# Contributing Guide

Thank you for improving this repository.

This repository is used as a learning and prototype workspace for TypeScript, React, API integration, and AI workflow patterns.

---

## Development Workflow

1. Create or update content in a focused branch.
2. Follow the naming convention in `docs/naming-convention.md`.
3. Keep examples beginner-friendly and practical.
4. Run type checking before proposing changes.
5. Update `CHANGELOG.md` when the change affects structure, scripts, modules, or learning scope.
6. Update `REFERENCE.md` when the change affects version, metadata, license, or repository governance.

---

## Commands

```bash
npm install
npm run check
npm run build
npm start
```

---

## Documentation Rules

- Use clear Markdown headings.
- Keep file names lowercase and hyphen-separated.
- Prefer short examples with comments.
- Explain why a pattern is useful, not only how to write it.
- Keep beginner and intermediate content separated when possible.

---

## Commit Message Style

Recommended examples:

```text
docs: update README structure
build: add TypeScript config
chore: update gitignore
feat: add API response model example
refactor: standardize file names
```
