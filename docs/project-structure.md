# Project Structure Standard

This document defines the baseline structure for `PhuminDecOKnoi/TypeScript-for-React-API-AI`.

---

## Root Structure

```text
.
├── .github/
│   └── pull_request_template.md
├── docs/
│   ├── naming-convention.md
│   └── project-structure.md
├── src/
│   └── main.ts
├── .gitignore
├── CHANGELOG.md
├── CONTRIBUTING.md
├── LICENSE
├── README.md
├── REFERENCE.md
├── package.json
└── tsconfig.json
```

---

## Folder Purpose

| Path | Purpose |
|---|---|
| `.github/` | GitHub workflow, pull request templates, issue templates, and repository collaboration files |
| `docs/` | Project documentation, naming rules, architecture notes, and learning notes |
| `src/` | TypeScript source code and starter examples |
| `dist/` | Compiled output generated by `npm run build`; this folder is ignored by Git |
| `node_modules/` | Installed dependencies; this folder is ignored by Git |

---

## File Purpose

| File | Purpose |
|---|---|
| `README.md` | Main landing page and project overview |
| `REFERENCE.md` | Repository reference register and version governance |
| `CHANGELOG.md` | Change history and release notes |
| `CONTRIBUTING.md` | Contribution and documentation workflow |
| `LICENSE` | Repository usage license |
| `package.json` | npm metadata and scripts |
| `tsconfig.json` | TypeScript compiler configuration |
| `.gitignore` | Files and folders excluded from Git tracking |

---

## Maintenance Rule

When project structure changes, update both:

1. `docs/project-structure.md`
2. `REFERENCE.md`

If the change affects users or learners, also update:

1. `README.md`
2. `CHANGELOG.md`
